Inicio/Privacidad

Privacidad

Qué datos pide la solicitud de reserva, para qué se usan y dónde se guardan.

Sitio de demostración: por favor no envíes datos reales.

Qué datos pedimos

Para una solicitud de reserva: nombre, correo, fechas, cantidad de huéspedes y, si quieres, un teléfono y un mensaje. No pedimos ni guardamos datos de pago.

Para qué

Solo para responder tu solicitud y, si se confirma, coordinar la estadía. No los usamos para publicidad ni los compartimos con terceros.

Dónde se guardan

En una base de datos de Supabase a la que el público no tiene acceso: el sitio solo puede crear solicitudes y consultar qué noches están ocupadas, sin ver datos de otras personas.

Cuánto tiempo

Mientras dure el sitio de demostración. Puedes pedir que borremos tu solicitud en cualquier momento, respondiendo el correo de confirmación.

Cookies

El sitio no usa cookies de seguimiento. Las tipografías y el visor 3D se sirven desde este mismo sitio.

Si eliges un idioma en el selector, el sitio guarda la cookie nf_lang con esa preferencia durante un año, para mostrarte las páginas en ese idioma.
