Privacidad

Sitio de demostración: por favor no envíes datos reales.

Qué datos pedimos

Para una solicitud de reserva: nombre, correo, fechas, cantidad de huéspedes y, si quieres, un teléfono y un mensaje. No pedimos ni guardamos datos de pago.

Para qué

Sólo para responder tu solicitud y, si se confirma, coordinar la estadía. No los usamos para publicidad ni los compartimos con terceros.

Dónde se guardan

En una base de datos de Supabase a la que el público no tiene acceso: el sitio sólo puede crear solicitudes y consultar qué noches están ocupadas, sin ver datos de otras personas.

Cuánto tiempo

Mientras dure el sitio de demostración. Puedes pedir que borremos tu solicitud en cualquier momento, respondiendo el correo de confirmación.

Cookies

El sitio no usa cookies de seguimiento. Las tipografías se sirven desde este mismo sitio y el visor 3D, desde jsDelivr.
