# Fotos de referencia

Coloca aquí las fotos del objeto a modelar. Recomendaciones para que el agente pueda medir:

- Al menos una vista **frontal** y una **lateral** lo más ortogonales posible (cámara a media altura, sin inclinar, lo más lejos que se pueda y con zoom).
- Una o dos vistas en **3/4** para volumen y techo.
- Detalles: puertas, ventanas, cornisas, materiales.
- Que aparezca un **patrón de escala** conocido (puerta, auto, persona, cinta métrica) o anota una medida real en `medidas.txt`.
- Nombres descriptivos: `frente.jpg`, `lado_izq.jpg`, `tres_cuartos.jpg`, `detalle_ventana.jpg`.

Estas fotos no se envían a ningún servicio externo salvo que lo autorices en el momento.
